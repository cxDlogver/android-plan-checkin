## 2. 逐项决策

| ID | 问题 | 答案与影响 |
| --- | --- | --- |
| T1 | 本地还是云构建 | Windows本地；Expo CLI＋Gradle Wrapper，无EAS云构建依赖 |
| T2 | 是否额外加密数据库 | 普通SQLite＋应用私有目录；不引入SQLCipher/SecureStore数据库密钥链路 |
| T3 | 系统备份与换机迁移 | 关闭；manifest和旧/新备份XML及实际目录一起验证 |
| T4 | 最低Android | Android10+、minSdk29；无需旧系统内阴影降级 |
| T5 | 版本基线 | SDK57稳定组合、Node24 LTS、JDK17；锁版本，不采用Beta |
| T6 | APK签名及更新 | 固定包名、长期release签名；新APK覆盖升级保留数据，密钥仓库外保管/备份 |
| T7 | 同字段多次编辑待生效规则 | 最后保存为准；当前与待生效同时展示，旧待生效版本保留并标被替代 |
| T8 | 验收矩阵与预算 | 已确认API29/36、360/393dp、100/200%字号；4核/4GiB API36 release，100计划×3年，冷启动≤3秒、切月/详情≤1秒；数据集不是数量上限 |
| T9 | 结束/截止编辑生效 | 已确认保存后立即生效；新日期不早于今天，未终结逾期任务可因延后截止转待完成；终态截止不可改 |
| T10 | 一次性结果语义 | 完成绿✓、失败红×、取消灰⊘独立明细；跳过橙—只用于循环；日期格改为统一完成汇总 |
| T11 / Q29 | 一次性日历归属 | 已确认未终结只在当前截止日计入，终态只在结果业务日计入并移除旧截止安排；延期将安排移至新截止日 |
| T12 | 取消待生效规则 | 保存回当前生效值即取消该字段申请；未触及字段不动，取消版本保留 |
| T13 | 统计显示区间 | 运行/暂停截至当前业务日；自然循环到期冻结结束日，其他归档冻结归档日；未开始不显示倒置区间；显示区间不扩大分母 |
| T14 | 应用名称与身份 | 计划打卡；正式com.xiang.plancheckin，开发com.xiang.plancheckin.dev；长期覆盖升级身份固定 |
| T15 | 技术整体共同理解 | 用户回复“确认技术0.8（推荐）”；确认9表DDL、11个命令/查询、日期/统计与构建验收四份详细规格作为实现基线；原生构建与APK仍待实测 |
| Q28 | 周目标日历总数 | 已确认仅当天已有周记录计入，不生成每日执行要求；失败/跳过仍计未完成 |

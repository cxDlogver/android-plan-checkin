# BDD执行与证据规则

> 版本1.0 评审稿；PRD/UI 1.1、技术0.8已确认；本轮P1明确固定星期默认不选。所有产品验收NOT_RUN，步骤定义尚未实现。

关联[实施计划](../实施计划-checklist-计划打卡-Android-v1.md)：120个场景、281个场景/Examples实例，再按设备范围扩展。

## BDD写法与勾选规则

采用Feature/Scenario/Scenario Outline/Examples及Given（场景前置）→When（操作/事件）→Then（可观察结果）。产品场景写业务结果，数据内部不变量另在预期断言中校验；工程验收单独分组。参数化场景每行独立结果，不能以一行通过勾整场景。[Cucumber Gherkin规范](https://cucumber.io/docs/gherkin/reference/)

- [ ] REVIEW — 用户确认BDD1.0与实施计划共同理解后成为执行基线。
- [ ] EXECUTION — 所有必需实例/配置执行完，预期断言全部PASS并有符合要求的证据后，才能关闭产品验收。

本次生成.feature供后续测试映射，不安装Cucumber、不引入新应用依赖；未提供step definitions/runner，不能宣称.feature已经可自动执行。领域测试用node:test，原生用.dev集成，UI用Appium，人工视觉/语音审查报告纳入同一实例。

AC父项只有全部A断言、E证据、Examples及设备配置都通过才能勾；状态为NOT_RUN/PASS/FAIL/BLOCKED。证据文件存在不足以PASS，需expected/actual和每条断言的值。未执行、阻断、失败不可勾选；重试保留失败报告，用新runId链接修复回归。

一个A编号包含多个事实时，expected/actual按字段保存完整对象或子断言列表，每个事实都必须匹配；不能只校验其中一个值就勾该A。原场景步骤不能由读取SQL替代，内部字段/约束证据作为可观察结果的补充。

实施项按计划中的退出范围独立完成：P2独立数据/规则AC不依赖UI；核心UI在P3/IP26先完成双API393正常字号，IP27追加八组合，AC父项仍等全范围。贡献关联不是退出前置，不能因领域通过勾端到端AC，也不能要求P3先完成后续矩阵/真实TalkBack或正式性能。

## 共同前置与数据定义

除明示日期外，功能可控Clock固定2026-10-09、zone=Asia/Shanghai，仅在.dev或领域测试中使用。10/xx均为2026-10-xx；正式离线/性能用实际业务today及相对日期夹具，正式APK不含Clock/seed/故障入口。每场景独立夹具，不依赖前一个场景的副作用；Examples分支分别重置。

历史夹具用合法startsOn/字段版本/阶段/结果生成，UI仍禁止新建过去开始日。UUID稳定、名字允许同名；原生数据证据仅合成测试数据，由唯一连接验证或完全停机后检查，不能再开业务连接。G1控制环境PASS、宿主SQL13项PASS及Pen参考图都不能代替产品实测。

固定率分子/分母与日历C/T必须分别断言；周进度与历史完整周率也分别断言。0/0表示暂无可计算项，不生成0%或100%。完成仅success/completed；failure/skip/unknown/pending/cancel都是日历未完成。

## 证据要求（每场景明确引用）

每次执行目录`resource/acceptance/runs/<runId>/<AC>/<rowId>/<configId>/`，普通场景rowId=default。runId使用不重复时间戳加构建摘要，configId至少编码API/宽/字号/构建类型；目录命名与报告一致。此为未来产物路径，当前只保存空模板，不造截图或数据。

全部实例强制有result.json、assertions.json、evidence-manifest.json，内容含基线版本、IP/AC/FR/AT、rowId/configId、源码/锁/APK摘要、实际设备和Clock/zone、fixture、起止时刻、步骤、expected/actual、每条A结果、每类E路径/SHA256、缺陷/回归/限制。

<a id="ev-ui"></a>

- **E-UI**：before.png/after.png及Appium操作日志、hierarchy.xml；以真实运行界面证明文字/计数/可用操作，不用Pen截图代替

<a id="ev-data"></a>

- **E-DATA**：facts-before.json/facts-after.json、assertions.json：ID/日期/类型/结果/相关行数/revision/摘要；开发包由同连接验证上下文读取，正式包用受控停机检查，禁止额外打开正在使用的业务库

<a id="ev-domain"></a>

- **E-DOMAIN**：规则测试输入快照、每条expected/actual、Clock/zone和node:test原始结果；不能替代原生或UI验证

<a id="ev-error"></a>

- **E-ERROR**：故障点/注入方式/是否真实系统故障、错误码、回滚前后逻辑摘要、重试报告；涉及UI的场景另有草稿保留截图，纯原生/服务不要求页面；日志无用户文本

<a id="ev-native"></a>

- **E-NATIVE**：实际API/AVD/serial/build/SQLite版本、技术参数读回、原生断言及logcat技术日志；声明development或release，不能用宿主SQLite替代

<a id="ev-build"></a>

- **E-BUILD**：commands.log逐命令退出码、真实依赖/Gradle解析、配置快照、manifest/XML与锁文件/源码/资源SHA256；不保留密钥密码

<a id="ev-privacy"></a>

- **E-PRIVACY**：最终APK权限/备份XML提取、日志敏感标记扫描、远程能力/测试入口排除检查及必要系统行为报告；未测厂商单列

<a id="ev-release"></a>

- **E-RELEASE**：build-manifest.json、APK SHA256/证书摘要/apksigner结果/debuggable读回、Metro/网络状态与独立安装运行记录

<a id="ev-visual"></a>

- **E-VISUAL**：同API/尺寸/字号的真实截图与对应Pen画板/令牌版本并排、控件dp/sp/字重/触控边界测量、人工差异结论；抗锯齿像素不要求逐像素相等

<a id="ev-a11y"></a>

- **E-A11Y**：实际TalkBack服务与遍历/操作记录、语义树、焦点顺序、人工听觉或可复核语音证据；不得只凭tree宣称语音正常

<a id="ev-semantic"></a>

- **E-SEMANTIC**：hierarchy.xml与label/role/state逐断言值；只证明中文语义可定位和状态表达，实际TalkBack听觉/操作另由AC094验证，不宣称语音PASS

<a id="ev-matrix"></a>

- **E-MATRIX**：M1–M8实际API/viewport/fontScale/导航读回，每个配置的每个核心AC实例报告与截图；不能合并为一个笼统PASS

<a id="ev-perf"></a>

- **E-PERF**：performance-raw.json完整样本和计时标记、fixture生成器/seed/hash/各表行数、median/P95/max/首次缓存、每次数量正确性断言

<a id="ev-upgrade"></a>

- **E-UPGRADE**：旧/新APK身份摘要、覆盖安装命令、schema/user_version和升级前后逻辑事实摘要、故障/重启结果；未卸载未清数据的证明

<a id="ev-trace"></a>

- **E-TRACE**：FR–AT–IP–AC–Examples–配置执行索引，缺陷/回归链接、证据manifest的相对路径/SHA256；所有必需实例结果可追溯

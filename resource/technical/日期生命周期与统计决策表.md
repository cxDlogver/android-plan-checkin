# 日期、生命周期与统计决策表

> 技术基线0.8，T15已整体确认；产品口径沿用[PRD/UI 1.1](../设计需求文档-计划打卡-Android-v1.md)及T12/T13。这里的“今天”始终是首次固定IANA时区中的业务日。

## 1. 执行阶段和权限

执行时间区间采用半开区间`[startAt,endAt)`。循环初始startAt为startsOn业务午夜；暂停关闭当前阶段；恢复从新业务午夜开启新阶段。manual archive的endAt为真实归档时刻，cycle_end为结束日次日午夜。日期资格与整周完整资格分别计算，不能仅按事件所在日期推断整天持续运行。

管理状态从创建时起派生，实际执行区间再与`[startsOn午夜,结束边界)`相交。未来计划在开始前暂停/归档时交集为空，不能构造endAt<startAt的负区间；恢复后的可执行起点为max(恢复边界,startsOn午夜)，补记仍受当前阶段和开始日双重限制。

| 情形 | 新增普通记录 | 新增历史记录 | 修改已有记录 |
| --- | --- | --- | --- |
| 当前运行、今天合法空日 | 允许确认后保存 | 不适用 | 普通今天可修正 |
| 当前运行、当前阶段的合法历史空日 | 不适用 | 允许，保存立即只读 | 历史/补记均拒绝 |
| 当前运行、旧阶段或暂停期间日期 | 不适用 | 永久拒绝 | 既有历史只读 |
| 暂停 | 拒绝 | 全部拒绝 | 历史只读；可申请恢复/归档 |
| 归档 | 拒绝 | 全部拒绝 | 全部只读；无恢复 |
| 已申请明天暂停、尚未生效 | 今天按原运行状态 | 当前阶段仍合法 | 普通今天仍可改；可取消申请 |
| 已申请明天恢复、尚未生效 | 仍暂停 | 仍拒绝 | 不解锁 |
| 固定非选定星期、开始前/结束后、未来 | 拒绝 | 拒绝 | 不可生成新记录 |

星期/N的初始版本从创建日生效，执行资格另受startsOn限制。resolveRule按每字段最新未取消版本求值；一次性终态引用首次终结时的due版本，后续修正不移动日期或截止引用。暂停申请本身不截断阶段，只有实际生效才截断。

## 2. 生命周期边界与对账

| 事件 | effectiveOn / effectiveAt | 归档/阶段行为 | 当日未记录要求 |
| --- | --- | --- | --- |
| 申请暂停/恢复 | 明天 / 明天业务午夜 | 关闭/新建阶段，生效前可取消 | 今天仍按原状态 |
| 手动归档 | today / 保存now | 立即只读、关闭阶段、取消未来申请 | 固定当日空要求取消；已记录保留 |
| 循环自然结束 | endOn+1 / 该日业务午夜 | 自动归档 | endOn有效要求保留，即使未记录 |
| 一次性普通终态 | businessOn+1 / 该日业务午夜 | 当日可改三结果，次日归档 | 结果项只属于businessOn |
| 一次性历史完成补报 | today / 保存now | 保存即归档 | 结果项属于实际完成日，不属于提交日 |

reconcile捕获now后，枚举到期原因和未取消状态申请，按effectiveAt排序处理；相同边界归档优先，取消该边界及以后未执行申请。自然归档保存原应生效时刻，不使用应用重新打开时刻。自然终态source_key使用稳定规则/结果ID，unique防止重复启动生成第二事件。

即时结束/截止变更在保存业务日追加版本。生命周期对账先于编辑：已经自然归档不能借旧页面延期；尚未终结的逾期一次性可把截止改至今天/未来，立即转待完成。归档取消尚未生效字段版本，历史版本保留。周一请求修改N也到下周一；T12保存回当前值取消待生效行。

## 3. 统计显示区间（T13已确认）

循环开始日为startsOn，一次性起点为createdOn。运行/暂停的displayUntil=today；循环自然归档冻结endOn，其余归档冻结archive.effectiveOn，包括一次性普通终态次日归档和历史补报当日归档。一次性结果业务日/实际完成日另列，不用提交日移动结果项。归档日与统计候选集合不必相同，显示区间不代表每一天都进入分母。

未来尚未开始且没有可回顾事实时，返回`period={kind:'not_started',startsOn}`，界面显示“尚未开始”，不显示开始日晚于截至日的倒置范围。已归档但在开始前即删除的未来循环计划返回`period={kind:'no_execution',startsOn,archivedOn}`，显示“尚未开始即归档”及两个日期，分子/分母为0/0，不伪造执行区间。

暂停空档不进入固定分母；今天未提交不进入固定历史分母；周统计只纳入已结束完整周。截止显示today仍可同时标“截至当前业务日，今天未提交不计入”，与已确认详情设计一致。零分母显示暂无可计算记录/暂无完整周，显示0/0但不算0%或100%。

## 4. 固定统计与连续

1. 从执行阶段与当日规则生成E：startsOn至统计边界内的合法选定星期；保留已归档记录；手动归档当日无记录从E排除。
2. 候选S=`{d∈E | d<today}`并入`{d=today且有记录}`；未来不参与。对已归档边界再截断，不按最近记录时间倒推资格。
3. numerator为S中success数；denominator为S中非skip数，包含历史未记录；skipCount单独返回；pastUnknownCount只数过去合法空日。
4. rate仅denominator>0时存在，UI四舍五入整数；内部保留整数分子分母与未截断数值。

连续按有效应执行日期及实际暂停边界扫描，success加1，failure/skip/已结束unknown归0；实际暂停即中断。非选日与未开始日期不计次数；今日合法但未提交不置0，保留昨日日终值。补记会改变完整历史推导，但不能越过暂停边界续接旧阶段。归档后的空日不产生新的失败或unknown。

| 示例 | 固定历史率 | 日历 | 当前连续 |
| --- | --- | --- | --- |
| 历史6/8；今天未提交 | 6/8 | 今天浅色无下标 | 保留昨日日终值 |
| 今天成功/失败 | 7/9 / 6/9 | 今天仍隐藏下标，明细可见 | 成功+1 / 失败归0 |
| 历史2成功、1跳过 | 2/2，跳过1 | 当日集合可为2/3 | 跳过打断 |
| 未来开始即归档 | 0/0，暂无 | 无空要求 | 0 |

## 5. 周目标统计与连续

对每个自然周w建立`[周一午夜,次周一午夜)`。fullEligible要求整个区间被一个连续运行阶段覆盖，且开始/结束界限覆盖全周；目标N为该周周一的生效值。成功次数按不同businessOn计数；成功/失败/跳过均只作为已有记录，不为周空日生成每日未记录。

历史达标率分母为`wEnd≤now && fullEligible`的周数，分子为其中successDates≥N的周数。当前周返回实际successDates/N、partial原因和进度条min(1,ratio)，不进入历史分母。部分周成功仍展示实际数量，但不把部分周误算达标完整周。

连续只扫描已结束自然周：完整达标+1；完整未达标/部分周/整周暂停归0；未开始与归档后完全不相交周不凭空加事件。正在进行的部分周/整周暂停先显示原因，结束时才打断旧连续。归档周若截至日已冻结但该自然周还未结束，连续仍保留此前已结束周值，到该周真正结束后归0，历史分母保持冻结；不能因归档页只读就停止时间派生查询。

| 边界 | 是否完整周 | 历史分母/连续 |
| --- | --- | --- |
| 周中创建/暂停/恢复/结束 | 否 | 不入分母；周结束中断 |
| 周一00:00暂停整周，次周一恢复 | 暂停周否 | 不入分母；暂停周结束中断 |
| 星期日17:00手动归档，即使3/3 | 否 | 不入分母；周结束中断 |
| 周日为自然结束日，次周一00:00归档 | 可完整 | 正常判断达标与连续 |
| 周一00:00合法N变更，整周连续运行 | 是 | 使用新N，不制造部分周 |
| 本周3/3尚未结束 | 当前进度达标 | 历史分母/连续尚不变化 |

## 6. 全局日历每日集合U(d)

每项稳定key=`planId:businessOn`，同计划同日只计一次。先收集保留记录，再生成无记录安排；记录优先，不能被当前暂停/归档状态抹去。所有汇总先构造完整U，再筛选明细。

| 分支 | 放入U(d)的条件 | completed |
| --- | --- | --- |
| 固定已有记录 | 合法保留的businessOn=d，含暂停/归档历史 | result=success |
| 固定无记录 | 当时选定星期、执行期/阶段有效；手动归档日及以后排除；自然末日保留 | false |
| 周目标已有记录 | businessOn=d，含失败/跳过及保留历史 | result=success |
| 周目标空日 | 永不加入；合法当前阶段历史空日另列backfill候选 | 不适用 |
| 一次性已有结果 | businessOn=d；替代所有旧截止安排 | outcome=completed |
| 一次性无结果、未归档 | 当前dueOn=d，只计一项 | false |
| 一次性无结果、手动归档 | 仅dueOn<archiveOn且d=dueOn；归档当日/未来安排取消 | false |

永久删除目标全部移出U。循环未来安排可投影，但尚未生效的暂停/恢复会影响相应未来日期；任何未来项不具备提交资格。计划详情日历使用同一函数按planId过滤，不另写分母口径。

```text
C = U中completed为true的数量；T = U.length
d=today → marker=none（浅色今天填充；选中边框独立）
否则T=0 → none
否则C=T → 绿色✓
否则 → 黄色10sp、600字重的C/T（日期为12sp）
```

失败、跳过、未标记、未终结安排、取消均未完成；今天不显示进度并不表示不计算C/T。筛选all/completed/incomplete只过滤明细，不改变日期标题T、C/T或统计；额外周补记候选不进筛选集合。月历下无含义介绍。Q29例：截止10/10，实际10/9完成、10/11补报→10/9完成，10/10安排移除；延期至10/15→未终结项移动至10/15。

## 7. 必须固定的边界样本

领域测试至少分别覆盖：2026-10-09/10午夜；上海/纽约DST23或25小时；2月闰日/月底/跨年；周一/周日修改N；规则待生效值取消；恢复后旧阶段拒绝；手动/自然归档末日差异；同边界归档与恢复；跨日已提交receipt返回成功；全跳过0/0；100项日历分数；一次性完成→失败→取消同日修正；归档前未来未开始；完整周与整周暂停时间轴。

这些是计划中的验收样本，不是当前应用测试通过记录；完整证据格式见[验收与构建证据规范](验收与构建证据规范.md)。

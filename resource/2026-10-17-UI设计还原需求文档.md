## 1. 唯一需求：UI-001

依据现有 UI 设计稿，还原“计划打卡 Android V1”的界面视觉，使各页面的布局、组件、颜色、字体、间距、圆角、渐变、阴影、图标及稿中可见状态与对应画板一致。

本轮只有 UI 设计还原这一项需求。本文的页面清单、视觉规范和验收检查点都是该需求的细化，不构成新增功能需求。

### 1.1 范围

- 覆盖页面映射中的全部 23 个页面或状态画板。
- 还原设计稿可见的页面结构、内容层级、组件外观、文案排版及状态样式。
- 选中／未选、成功／失败／跳过、只读、警示等已有设计状态，按各自画板呈现。
- 稿中按钮、筛选、表单等控件的可见样式属于本轮范围；业务操作是否完成、数据如何存储和统计如何计算，不作为视觉还原的前置条件。

### 1.2 边界

**仅考虑 UI 设计。历史 PRD、历史决策、业务流程与业务规则均不作为本轮需求或验收的前置条件。**

未提供视觉稿的状态，不自行补成新设计；不从历史文档推导新增页面、默认值、交互流程或功能要求。本轮不要求先完成业务能力再开展 UI 还原。

本文不指定实现技术和代码改造方案，也不判断当前页面的完成度、缺陷或工作量。编写期间未读取已有实现代码。

## 4. 统一视觉规范

本节参数来自设计令牌和设计树。局部特殊样式以对应画板及节点为准。

### 4.1 风格与材质

- 冷银灰背景、银色金属面板、斜向反光带、边缘高光、轻外阴影与局部内阴影。
- 主要按钮保留多段银色渐变；选中控件保留稿中深石墨或对应浅色选中表现。
- 卡片、输入框、按钮、标签沿用各自样式；保持小圆角和直角感，不改成大圆角或胶囊。
- 保留主次按钮、结果按钮、危险操作与警示区域的视觉层级。
- 已画出的渐变、高光、阴影不简化为单色平面样式。

### 4.2 色彩

| --- | --- |

### 4.3 字体与布局参数

| 项目 | 设计基线 |
| --- | --- |
| 字体 | Noto Sans SC；回退字体需核对字形、字重、换行和布局差异 |

| 区块标题 | 16sp／700 |
| 正文／辅助文字 | 15sp／12sp |

### 4.4 日历画板重点

仅对齐图11已有视觉，不据此追加统计算法或日期业务规则：

- 月份标题、切月箭头、周一起七列、日期格、选中边框与列表区按稿定位。
- 稿中今日为浅银灰填充与加粗日期，不显示点、勾或分数；选中日期使用独立边框。
- 绿色勾、金黄色小分数、无下标日期及跨月弱色日期，分别对齐画板中的状态样例。
- 日期 12sp，分数 10sp／600、#866500；保留字号层级，不将分数放大为日期字号。
- 月份栏有效左右边距16、日期容器左右2、列间2；星期与日期列居中对齐。
- “日期 · 项数”标题下的状态筛选框、计数排版、彩色结果与明细间距按稿呈现，不增加稿中没有的解释行。

加载、字段校验、保存中、其他异常、额外空态等场景，如没有完整视觉依据，不在本轮补充设计，也不将历史文字描述转成新增 UI 验收项。

本轮不追加业务数据准备、统计计算、存储、权限、路由闭环或跨日逻辑的完成条件。视觉对照可以使用对应场景的数据展示，不要求先打通全部业务流程。

设计资料未给出逐页新稿的设备尺寸、字号组合或主题，不从历史文档补入额外验收矩阵；本轮以现有画板参考尺寸核对视觉。

## 6. UI-001 验收标准

以下均为同一需求的视觉检查点，不是独立功能需求。验收关注“界面是否与稿一致”，不以业务能力完成作为前置条件。

| 检查点 | 通过条件 |
| --- | --- |
| A01 覆盖完整 | 第3节23个画板均有对应视觉对照，画板内已有状态样例不遗漏 |
| A02 布局一致 | 标题、分区、卡片、字段、按钮、导航的顺序、位置、对齐、留白及纵向关系与对应画板一致 |
| A03 视觉参数一致 | 色彩、字号、字重、圆角、间距、渐变、高光和阴影符合设计参数，局部差异按对应节点核对 |
| A04 组件一致 | 输入框、选项、标签、按钮、进度、日历和提示面板的样式、尺寸关系、图标及文案层级与稿一致 |
| A05 状态一致 | 稿中已画出的选中／未选、彩色结果、只读、警示等视觉状态分别可对照；不要求业务逻辑先生成这些状态 |
| A06 比例正确 | 以393dp逻辑宽度核对，2×导出图不误用为786dp页面；长画板不压缩变形，内容保持设计比例 |
| A07 日历一致 | 图11日期、分数、勾、今日底色、选中边框、跨月弱色、筛选框与明细列表符合第4.4节 |
| A08 证据明确 | 逐页标注画板编号、对应截图、参考尺寸、状态及差异复核结果；未核对项明确标识 |

### 6.1 视觉对照方式

- 按相同逻辑宽度、字体比例与场景，进行并排或叠加对照。长画板使用完整滚动截图或连续截图，不拉伸压缩。
- 优先核对页面结构和组件定位，再核对文字、颜色、材质、图标及细部间距。
- 动态内容可不同，但排版、层级、尺寸关系和所展示状态应与参考场景对应。
- 设计资料没有给出相似度百分比或像素误差容限，不虚构已确认阈值；依据明确参数及逐页差异复核判断。
- 发现差异时记录画板与具体位置；不以历史 PRD 或业务实现状态替代视觉对照结论。

### 图01 今日空态

来源：PRD第3节图01；画板bCoiJ；对应PNG；设计树同名画板及节点。

纳入条件：呈现图01的今日空态：中部为空态引导卡片，下方为介绍文字与三入口导航。

- 底部今日导航使用强调色，其余两项为辅助色。

局部对齐检查：

- 空态面板：保留斜向高光带、线性记事图标和标题层级；空态标题按局部节点25sp核对。；创建按钮位于面板内，保留金属渐变、边缘与阴影。

本轮边界：不据空态外观推导数据库为空或读取成功条件。；不把创建按钮的可见外观转为创建路由验收。

### 图02 今日有计划

来源：PRD第3节图02；画板yB844；对应PNG；设计树同名画板及节点。

纳入条件：呈现图02的今日有计划长画板：需要处理、本周可记录、截止提示、已记录四个区域均有样例。

当前事实：

- 周目标卡片含2/3天样例、横向进度与记录按钮。
- 截止提示使用警示浅底，已记录卡片含成功标签、时间备注和次按钮。

局部对齐检查：

- 需要处理的两种卡片：要做卡片保留完成／未完成／跳过文案；不要做卡片保留做到了／发生了／跳过文案。；绿色、红色、橙色的文字和边框分别核对，绿色按钮的浅底及阴影以当前画板为准。
- 本周进度与截止提示：保留数字标签、深色已填段与浅灰轨道的比例和位置。；截止提示的文字、浅黄底与所在分区关系按稿核对，不转成进度或截止算法。
- 已记录卡片与导航：成功标签、备注和次按钮构成独立卡片层级；底部今日导航保持强调。；逻辑高度1140的完整内容保持比例，使用完整或连续截图对照。

展示参数：计划名称、日期、数量、进度数值、截止样例、时间与备注。

本轮边界：不推导四区域的数据筛选与排序算法。；不要求结果按钮完成真实记录写入。

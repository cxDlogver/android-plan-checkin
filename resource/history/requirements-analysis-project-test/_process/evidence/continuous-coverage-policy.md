# 当前需求图的连续覆盖政策

来源：本对话中用户连续澄清与最新修改指令。

用户要求：
> 需求节点的遍历一样需要从起点出发到达节点，或者是从当前的位置可以直接通过有向边到达节点，不能是用广度优先或深度优先算法直接跳到上一轮的节点，允许回路，允许重复到达，允许重复经过节点。

随后讨论允许重新从真实起点出发、重启不计需求访问次数的模型；助手说明最小费用流和路线用边投影后，用户指令：
> 修改规范并修改当前的需求图，保留必要的有向边

本轮采用：需求访问每次成本 1；允许重新从已声明真实入口开始，重启成本 0。重启是路线分段，不添加业务迁移，不自动重置业务数据。不把结构最优视作业务可执行，不改变 PRD/UI 的需求、状态或条件。

- 目的/入口：安装后直接进入今日，免登录；数据库读取完成且计划数为0才展示空态。
- 展示：应用定位、一句本机说明、“创建第一个计划”按钮；不预置样例计划。
- 操作结果：进入统一新建页，默认类型为固定日期循环（P）；已存在数据直接显示真实内容。
- 异常：读库失败显示FR32错误状态，不显示“开始使用”伪空态。
- 验收：AT01。设计图01。

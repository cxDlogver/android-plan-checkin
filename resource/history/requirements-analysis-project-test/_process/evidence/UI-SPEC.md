## 1. 体验定位

个人计划与执行记录簿。免登录，进入今日，选择结果后确认保存，再在日历与详情回顾。失败、跳过、未记录各自准确，不以自动完成、排名或催促代替主动申报。

三个底部入口：今日、日历、计划；今日右上角本机设置。二级页返回来源，保留筛选/日期。延期能力没有不可用按钮。

## 2. 视觉系统

采用银灰金属面板、斜向反光带、渐变边缘与内外阴影；深石墨选择态。卡片3、按钮2、标签1的低圆角，标题700，颜色与材质见[设计令牌](design/design-tokens.json)。

| 项目 | 要求 |
| --- | --- |
| 页面边距 | 常规左右20；卡片内16；内容块间16 |
| 月历边距 | 月份栏有效左右16、上下16；日期容器左右2、列间2 |
| 参考视口 | 393×852；长画板代表滚动内容，不整体缩放 |
| 月历日期 | 393宽约48.14×48；360宽需紧凑外边距保持48dp命中；日期12sp、分数10sp/600金黄色 |
| 字体 | 可读中文字体、APK内置或明确回退；标题粗体 |
| 结果 | ✓成功绿色、×失败红色、—跳过橙色；○未记录与空白区分 |
| 触控 | 可交互区域至少48×48dp，阴影不侵占命中区域 |
| 输入 | 浅内阴影表达凹入层级，字段错误贴近并可朗读 |

金属渐变不能损害对比度，状态同时有形状、文字和颜色。辅助文本与长中文在大字号下须运行验证。浅色是本轮视觉方案，深色主题作为延期提案。

## 4. 已确认交互规则

- 新建固定星期默认七天全部未选；用户手动选择至少一天或点击“每日”后才允许保存，全部取消则再次禁用。图04为已选后的操作示例；编辑页仍加载当前/待生效规则，不套用新建默认值。
- 今日结果按钮只预选并进入确认页；最终保存才写入，结果与文字备注一起提交。
- 未归档普通记录仅计划业务日期当天可改结果/备注；过去记录只读；补记保存后立即只读；不允许撤回。
- 暂停时禁止补记；恢复后不能补暂停前日期，只开放新执行阶段；暂停/恢复从明天生效。
- 运行或暂停计划删除后立即归档，不清历史；归档全部只读、无恢复，仅查看或永久删除。
- 完成率统计全部历史，显示开始日、截至日、分子/分母；今天未提交排除，今天提交立即计入。
- 跳过排除固定完成率分母，单独显示数量；部分周不计周达标率，在周结束时中断连续；未结束前保留此前值。
- 每周N修改从下周一生效，固定星期从明天生效；实际完成日期判断一次性是否按时。
- 日历日期格除今天外只显示一个下标：T>0且全完成用绿✓，否则C/T；零项留空。今天使用浅色填充和加粗日期，无实心点、勾或完成分数。失败、跳过、未记录/待处理、取消均未完成。选日标题显示日期/T，下面用全部/已完成/未完成筛选框和逐条真实结果；明细保留绿✓、红×、橙—、灰○/⊘。
- 每日集合按FR14：有效固定项（含未记录）、当天已有周记录、未终结一次性的当前截止安排或终结后的结果业务日；同计划同日唯一。周空白不计，周达标不自动给其他日勾；一次性结果替代截止安排，延期移动旧安排。
- 日历分母包含跳过，固定历史率继续排除跳过；2成功＋1跳过分别显示日历2/3与固定历史2/2，不能共用统计口径。首次使用固定时区、全部计划共用。历史周统计只纳入已结束周。
- Q31：首次记录页跨午夜，阻止旧提交并保留输入；合法循环历史日/一次性过去完成日显式进入补记确认，提示只读与适用的立即归档后才保存。跨日后状态导致不能补记时说明原因；一次性失败/取消重新确认新的当日结果；不得自动移动日期或静默转补记。图23主按钮只导航，不直接写入。
- Q32：整周暂停不进周达标率分母，该周结束时打断连续；结束前保留此前值，恢复后第一个完整达标周结束时连续为1。

跨月格保留真实日号并弱化颜色；完整日期区分9月28/29/30日与11月1日，点击和无障碍仍按真实日期。一次性详情不显示固定历史完成率或连续打卡，但结果仍参与日历完成数量。当日修改加载当前已保存值，原提交/最近修改信息单列。

循环结束次日自动归档；一次性普通终态次日、历史补报立即归档。暂停完全不可编辑，只可改状态；运行中编辑规定字段，归档只读。

手动归档当日保留已有记录，取消未记录要求；自然结束日要求保留。实际完成日不早于创建、不晚于今天；同日修正不移动记录日期。固定连续只当前值，暂停打断。

日历零项不显示0/0或全完成；未来固定/截止安排显示0/T并说明“未来安排”，不能提交。今天背景使用浅银灰$primarySoft，不依完成情况变化；选中边框独立于今天填充，今日下标始终隐藏。跨固定时区午夜后刷新今天及原今日下标；选中日不被强制跳走。分数使用金黄色$calendarProgress（#866500）、10sp/600且小于日期12sp，保留完整分子/分母；大数及200%字号在斜杠后换行、统一增高整个月日期行，禁止截断或禁用字号缩放。TalkBack读出完整日期、今天/选中/未来状态；今日格不朗读隐藏进度，选择后从筛选选项的计数读取完成数/总数。

编辑按字段说明：名称/说明、循环结束/未终结截止即时；固定星期次日；N下周一。多次待生效规则以最后保存为准，同时展示当前值和待生效值；只改名称不覆盖待生效规则。最低Android10+，矩阵API29/36、360/393dp、100/200%字号，应用验证仍NOT_RUN。

T12/T13已确认的细则沿用现有设计组件：编辑初值优先待生效值，保存回当前值即取消该字段申请；详情区间运行/暂停截至当前业务日，自然循环到期截至结束日，其他归档截至归档日，显示区间不扩大统计分母。未来未开始/开始前归档用说明态避免倒置期间；不增加新的按钮或页面，Pen参考画板继续使用已确认1.1。

## 5. 未画出的交互状态

| 场景 | 行为 |
| --- | --- |
| 本机读取中 | 加载态，不伪装无计划 |
| 字段非法 | 字段旁错误，可朗读，阻止最终保存 |
| 保存中 | 按钮禁用、防重复、朗读保存状态 |
| 保存成功 | 落盘后提示已保存到本机，来源页和统计更新 |
| 写入失败 | 保留输入、原数据不变、可重试；图20 |
| 初始化/迁移失败 | 专门错误说明，禁止清库或显示空态 |
| 未保存离开 | 继续编辑/放弃；草稿仅本次会话，重启不恢复未提交输入 |
| 跨午夜编辑 | 保存前重判权限，过日拒绝修改 |
| 首次提交跨午夜 | 图23保留输入且不写入；重新校验，合法时进入补记确认；非法时解释并返回查看 |
| 列表空筛选 | 解释筛选状态，可返回其他分类 |
| 删除确认 | 移入归档和永久删除两套文案/入口，不混用 |
| 周目标部分周 | 说明原因，保留实际记录，不参与完整周达标率 |
| 周目标整周暂停 | 不进达标率；周结束才中断连续，恢复不跨暂停周累计 |
| 日历状态筛选 | 日期/T标题下放48dp下拉框，全部/已完成/未完成带未筛选计数；只筛明细，切日重置、记录返回保留；Back/外部关闭；空结果明确提示 |

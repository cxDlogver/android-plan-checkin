# 减少重复验收

本轮按变更影响补充证据，未降低实施计划和 BDD 的原始门槛。

- 已通过的创建、保存、生命周期命令不重复提交；恢复准确的原事实作为 Given，只补未完成的观察与断言。
- UI 只补当前字体、布局、短标签、日历格子、键盘与系统栏的证据；八组合完成后停止截图和复查。
- 日期/查询缓存使用 43 份实际快照、856 次完整 DTO 对比及日期边界对比；快照读取消重复 SELECT 使用 87 次差分对比。迁移、命令及备份逻辑未变的原证据按精确源码范围复用。
- 失败的性能系列发现首个冷启动已超过固定门槛时提前停止，省去剩余 49 个样本；后续观察器中断保留 34 个有效样本，只补 16 个详情样本。最终 10/20/20 个样本齐全，P95 门槛保持 3000/1000/1000ms。
- 当前正式包 API36 执行完整发布专项；API29 只补准确包身份、离线启动及重启读回，复用其已通过的保存、升级和备份证据。
- AC100 最终交付进行一次闭合证据 SHA 核对；参数进度报告复用该已核验清单，避免再次全量读取证据。

原始失败、中断和恢复来源均保留。没有测量或虚构节约的 token 数量。所有机器可读进度见 [state.json](state.json)，正式交付范围见 [验收完成报告.md](验收完成报告.md)。

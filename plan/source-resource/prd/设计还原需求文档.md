## 1. UI-001：UI设计还原

依据已建立的JSON结构，还原“计划打卡 Android V1”的界面视觉。后续以JSON定义的节点关系、布局约束、尺寸策略、固定文案、动态占位、图标和视觉配方进行对齐，不再直接以设计稿、HTML或PNG作为验收依据。

本轮仍只有UI设计还原这一项需求。页面状态、固定说明及数据展示用于视觉对照，不据此增加数据存储、统计、业务路由、跨日处理等业务完成条件。

### 1.1 界面浏览范围

从今日页进入，按现有控件建立纯UI浏览流程。点击、选择和返回用于切换视觉画面；验收动作前后的界面事实，不验收存储、统计等功能效果。页面进入和返回属于本轮视觉浏览要求，不能因不实现业务功能而省略。

页面所含的保存、删除、暂停、跨日等说明仍是需要还原的可见文案。显示相应画面不代表已经执行文案描述的业务效果。

### 1.2 数据展示与对齐

示例数据不要求等于UI设计稿中的具体值。名称、用户输入、日期、时间、计数、统计比例及版本号等在UI JSON中使用动态占位，固定标签、按钮、状态语义和说明文案继续按JSON对齐。占位字段声明类型、显示格式及固定句式，不保存原图示例值作为默认值。

视觉预期由当前JSON与本次明确传入的场景数据共同确定；实际界面使用同一输入，核对解析后的格式、文字流、图形比例、结构及外观。数据可以改变换行和内容高度，不能为贴合原稿的示例宽度裁剪或缩小字号。缺少必需数据时，不能以原稿值或未解析占位符代替。

浏览同一对象时，按场景传入同一份数据或明确字段映射；设计稿中不同的示例名称或日期不作为固定前提，不据此要求页面切换后加载不一致的样例。此要求只约束UI展示输入，不扩大存储、统计或跨日等功能验收范围。

## 3. 覆盖范围与结构决策

- 覆盖清单中的23个页面、2个组件；方案概览保留为说明结构，不算新增应用页面。
- 23个页面的逻辑宽度均为393，按768断点归mobile；常规参考高度852，长画板保留其referenceSize。未提供desktop，不新增运行平台字段。
- 一维容器使用Flex；日历星期与日期分别使用七列Grid。页面布局采用flow，每个容器只有一种确定结构。
- mobile画布宽度填充可用区域，上限480并居中；320为本版计划验证下限。W>=768选择desktop，而本次设计尚未提供该类页面。
- 页面主内容为唯一业务纵向滚动区；页头和已有底导航位于其外。
- 文字可随系统字号放大并换行，容器可增高；具体短文本单行、固定图标、等权和比例策略以节点JSON为准。
- 环境区域和键盘按宿主实际insets处理一次；JSON中的环境托管样例不由业务重复绘制。

具体节点规则与取值只维护在JSON中，本需求文档不再复制另一套色值、字号或页面结构表。

## 4. UI-001验收

| 检查点 | 通过条件 |
| --- | --- |
| A01 覆盖 | manifest中的23个页面均有实现与对照，已有状态样例不遗漏 |
| A02 结构 | 节点层级、顺序、Flex方向、Grid轨道、等权和滚动边界与JSON一致 |
| A03 外观 | 字体、颜色、圆角、描边、渐变、阴影与styleRef解析后的配方一致 |
| A04 尺寸 | 按fixed/content/fill/fraction/percent/viewport执行，不能整体缩放页面或用图片像素当逻辑尺寸 |
| A05 适配 | 按rules矩阵检查窗口、长文案、字号和键盘，无业务横向溢出或关键内容裁剪 |
| A06 平台区域 | 安全区只处理一次，平台样例不由业务页面重复绘制 |
| A07 证据 | 记录JSON版本、页面与节点ID、实际环境、本次输入数据、截图及差异结果 |
| A08 依据 | 后续对照仅使用JSON及其生成的参考界面，不以旧设计来源裁决 |

JSON结构校验通过不代表实际应用视觉验收通过。像素相似度阈值未定义，不自行宣称已达到某个百分比。

# 状态迁移图 HTML 设计规范

## 1. 适用范围与文件关系

本规范规定状态迁移图查看页面的内容、布局、交互和验收方式。生成、修改或审查状态迁移 HTML 时读取本规范，使用 [graph.template.html](../assets/graph.template.html) 作为页面模板。

页面读取已确定的状态、迁移、全局约束及必要元数据。字段含义遵循[数据契约](contract.md)及 [state-transitions.schema.json](../assets/state-transitions.schema.json)。页面负责呈现和查看这些内容。

| 文件 | 职责 |
| --- | --- |
| 本文档 | 定义页面行为和可观察的验收标准 |
| graph.template.html | 实现页面结构、样式与交互，供生成器复用 |
| scripts/analyze.py | 将图 JSON 嵌入模板，生成同目录 HTML 并检查模型同步 |
| scripts/test_canvas.js | 模拟验证图的选择、布局和交互不变量 |
| state-transitions.json / state-transitions.html | 项目最终交付的模型及查看页面 |

分析、澄清、范围映射及门禁记录按 Skill 的独立工作记录规范处理。最终页面只展示状态、迁移、全局约束及必要元数据；不增加这些过程记录的展示区。本文档和模板作为 Skill 的通用能力文件保留，过程资料按 [SKILL.md](../SKILL.md#7-最终产物与清理) 清理。

## 2. 页面组成与阅读顺序

页面由标题区、图表工具栏、Canvas 图区、侧栏开关和详情区组成。

| 区域 | 内容与行为 |
| --- | --- |
| 标题区 | 图标题、修订信息及状态、迁移、全局约束数量 |
| 工具栏 | 适应范围、缩放、重置布局、全局约束；可提供聚焦状态选择器 |
| Canvas 图区 | 状态节点、有向迁移、起点标记及简短操作提示 |
| 侧栏开关 | 位于详情区边缘；详情收起时保留展开入口 |
| 详情区 | 根据选中对象展示状态事实、迁移信息或全局约束 |

初次打开时展示全图，详情区展示全局约束，侧栏展开。取消图下方的状态及迁移选择列表。顶部的聚焦选择器属于辅助入口，不替代 Canvas 点击操作。

图与侧栏可并排显示时使用左右排列；空间不足时允许上下排列。两种排列均须保留侧栏开关和图表操作入口。详情内容独立滚动；图片、长文和断言不能挤出图表的可用区域。界面尺寸变化只更新画布尺寸和重绘，不重新安排节点或自动缩放。

## 3. 图形与信息表达

### 3.1 状态节点

每个状态对应一个节点，显示状态 ID、可读标题和事实摘要。起点使用独立标记，选中状态使用可辨认的强调样式。颜色、边框、文字尺寸和间距使用模板统一样式，同类元素保持一致。

标题和摘要按节点的可用空间展示；完整内容保留在详情区。文字应能在适当缩放后清晰阅读，不以来源文件名替代状态标题。

### 3.2 有向迁移

每条迁移显示从初态指向终态的曲线、箭头和标签。标签包含迁移 ID、动作名称；仅在该迁移存在 condition 时补充分支说明。长标签可缩短，完整动作及条件在详情区呈现。

同一对节点间的多条边使用可区分的路线；自环保留方向和标签。边标签尽量避让节点与其他标签，必要时使用引线指向对应曲线。路线及标签依据全图计算，聚焦时沿用原结果。

选中迁移时，其曲线、箭头、标签和引线在其他迁移与状态节点之后绘制，形成最高显示层级。指针命中顺序与绘制层级一致；重叠位置优先命中当前选中迁移。

### 3.3 全局约束

全局约束在详情概览中集中展示，每项显示规则陈述和直接来源。不把全局约束转换为额外状态节点，也不在每个节点详情中复制同一组规则。

## 4. 默认布局：按最少迁移次数分列

使用有向图的最短迁移次数确定列。每经过一条迁移计一次，不按动作耗时、条件数量或页面名称计算。

1. 将所有 isInitial=true 的状态同时作为搜索起点，距离设为 0。
2. 沿迁移的 from → to 方向进行广度优先遍历，得到各状态距任一起点的最短距离 d。
3. 将距离为 d 的状态放在第 d+1 列；所有起点位于第一列。
4. 同一状态存在多条到达路径时采用最短路径；循环与返回边不增加已确定的最短距离。
5. 同列按状态 ID 稳定排序，使用统一节点尺寸、列距和行距。相同输入与相同模板参数得到相同初始位置。

例如：A 为起点，存在 A→B、B→C、A→C、C→D、D→B 时，第一列为 A，第二列为 B 和 C，第三列为 D。A→C 使 C 的距离为 1，返回边 D→B 不改变 B 的列。

节点的初始坐标采用以下关系，具体尺寸和间距由模板统一定义：

~~~text
列号 = 最短距离 + 1
x = 左侧留白 + 最短距离 × 列间步长
y = 顶部留白 + 同列行序号 × 行间步长
~~~

列间步长须大于节点宽度，行间步长须大于节点高度。独立起点同样位于第一列；不可达状态由图校验处理，不为调整展示而修改起点标记。

首次加载和“重置布局”执行默认布局。状态选择、迁移选择、聚焦切换、侧栏展开收起及画布尺寸变化均不触发布局重算。

## 5. 操作规则

### 5.1 点击、拖拽与层级

| 操作 | 结果 | 保持不变的内容 |
| --- | --- | --- |
| 拖动状态节点 | 更新该节点的位置，关联边跟随节点连接位置变化 | 图 JSON、其他节点坐标和当前缩放 |
| 拖动迁移曲线或标签 | 调整该迁移的曲线形状，标签随路线更新 | from、to、起终点连接关系及节点坐标 |
| 点击迁移 | 选中迁移、提升至最高显示层级，并展示迁移详情 | 当前聚焦范围、节点坐标及视口 |
| 拖动图中空白区域 | 平移视口 | 节点及边的图内坐标、缩放比例 |

使用位移阈值区分点击与拖拽。拖拽结束后不追加一次点击，不因拖动状态而切换聚焦。拖动边时保留原始起终点，曲线端点继续连接对应节点，不改变迁移方向。

拖拽位置、曲线调整、选中项、聚焦状态、侧栏显隐及视口只保存在当前页面内存中。刷新页面恢复默认视图；不把展示数据写入最终图 JSON。

### 5.2 点击状态与聚焦范围

点击状态 S 时，同时选中 S、展示状态详情并聚焦 S；再次点击同一个聚焦状态 S 时，恢复全图，详情仍展示 S。聚焦期间点击另一个可见状态 T 时，切换为聚焦 T。

“相关元素”按下式确定：

~~~text
可见状态 = S + 所有直接进入 S 的状态 + 所有从 S 直接到达的状态
可见迁移 = from=S 或 to=S 的迁移
~~~

直接进入与直接离开均只计算一条边，不递归展开路径。相邻状态之间若存在不经过 S 的边，该边仍隐藏。S 的自环可见，其他状态的自环按同一规则判断。

聚焦及恢复全图只改变可见性：

- 保留全部节点的原坐标，包括用户拖动后的位置。
- 保留可见边的曲线及标签位置；不因相邻边隐藏而重新计算分流位置。
- 保留缩放比例和平移偏移；不自动调用“适应范围”。
- 隐藏的状态及迁移不响应指针命中；恢复全图时仍使用隐藏前的位置。

聚焦选择器使用同一可见性规则。选择“全图”或按 Escape 恢复全图；这些操作同样保留坐标与视口。

### 5.3 详情收起与展开

侧栏边缘放置收起按钮，按钮属于独立的开关区域，不放在会被隐藏或替换的详情内容内部。

| 当前状态 | 按钮 | 点击结果 |
| --- | --- | --- |
| 详情展开 | 收起详情，箭头朝收起方向 | 隐藏详情，保留开关，图表使用释放的空间 |
| 详情收起 | 展开详情，箭头朝展开方向 | 恢复详情及已有内容，图表恢复对应可用空间 |

按钮文字、箭头、aria-expanded、aria-controls 和可访问名称须与实际显隐一致。连续收起和展开可重复执行。侧栏收起时选中其他节点或迁移，只更新详情内容，维持收起状态；展开后显示最近一次选中对象的信息。

切换侧栏后按新容器尺寸更新 Canvas 像素尺寸并重绘，保留节点坐标、曲线调整、聚焦范围、缩放比例和平移偏移。窄视口采用上下排列时，开关同样始终可用。

### 5.4 缩放、适应范围与重置

- 缩放：以指针所在位置为缩放中心；工具栏缩放以图区中心为基准，不修改图内坐标。
- 适应范围：调整视口，使当前可见节点、曲线及标签进入可用图区；保留已有布局和拖拽结果。
- 重置布局：恢复全图、清除节点拖拽和曲线调整，重新按最短迁移次数分列，并适应全图。
- 全局约束：切换详情内容，不改变当前聚焦范围和布局。

缩放范围由模板统一限制。空图显示明确说明，并保留查看全局约束的入口；不添加占位状态或迁移。

### 5.5 键盘与 Canvas

Canvas 可获得键盘焦点，焦点样式可见，并提供简短操作说明。底部列表移除后，保留以下键盘入口：

| 按键 | 行为 |
| --- | --- |
| 方向键 | 按稳定顺序选择当前可见状态并展示详情 |
| Shift + 方向键 | 选择当前可见迁移，展示详情并置顶 |
| Enter | 对当前选中状态执行聚焦切换；选中迁移时保持选中并展示详情 |
| Escape | 恢复全图，保留布局和视口 |

指针位置须换算为 Canvas 内坐标，再根据平移与缩放换算为图内坐标，确保缩放或侧栏宽度变化后的命中位置正确。按实际设备像素比设置 Canvas 像素尺寸，使用 CSS 逻辑尺寸计算布局，避免文字模糊或命中偏移。

## 6. 详情内容

### 6.1 状态详情

依次展示状态 ID、标题、起点标记、完整事实陈述，以及以下有实际内容的部分：

1. 视觉事实：强调可读陈述，展示观察方法；验收断言可折叠查看。
2. UI 结构与原截图：展示结构文件链接、documentId、nodeIds 和原截图；截图可打开查看原文件。
3. 功能事实：展示事实陈述、观察方法及可折叠的验收断言。
4. 其他直接来源：展示正式文档路径、条款位置及原文摘录。

视觉事实使用 UI 结构及适用规则作为预期。原截图用于定位和阅读来源；动态数据按结构中的绑定及场景输入理解，不把截图中的示例值转换为固定验收值。图片保持原始比例，来源内容完整可访问。某类事实为空时省略该部分。

### 6.2 迁移详情

按 GIVEN—WHEN—THEN 展示“初态—操作（条件）—终态”：

| 部分 | 内容 |
| --- | --- |
| 标题 | 迁移 ID、动作名称及初态 → 终态标题 |
| GIVEN | 初态的完整事实陈述 |
| WHEN | operation 中的执行者和动作名称 |
| 事后分支 | 仅在存在 condition 时展示条件陈述及观察方法 |
| THEN | 终态的完整事实陈述 |
| 动作输入 | 仅在存在 operation.input 时展示实际输入 |
| 分支结果样例 | 仅在存在 condition 时展示 sampleOutcome |
| 结果关系 | 仅在存在 effects 时展示陈述和断言 |
| 直接来源 | 支持动作及结果的正式文档或 UI 引用 |

单一确定结果不显示占位条件、空分支区或结果样例。按数据契约读取内嵌 operation，不生成独立 operation ID。

### 6.3 约束概览

显示每项全局约束的完整陈述及直接来源。没有额外约束时显示明确空提示。概览保持规则可读，不加入需求分析或澄清过程面板。

## 7. 模板生成与数据同步

模型通过模板内的 application/json 脚本块嵌入，保留模型哈希标记。由 [analyze.py](../scripts/analyze.py) 按统一序列化与哈希算法生成 HTML；嵌入模型须与同目录图 JSON 一致。模型文本转义后再嵌入，详情中的标题、陈述和来源内容同样按文本安全展示。

脚本和样式无网络依赖，UI 结构与图片引用已有原文件，并相对生成后的 HTML 正确解析。链接及截图使用直接来源路径，保持文件关系，不为展示复制一套来源资料。

修改模板后，重新生成需要更新的项目 HTML；只修改查看页面不能替代更新通用模板。查看器操作不修改模型及其哈希，也不引入额外的状态、迁移或全局约束。

~~~text
python <skill-dir>/scripts/analyze.py render <output-dir>/state-transitions.json --workspace <project-root>
python <skill-dir>/scripts/analyze.py check <output-dir>/state-transitions.json --workspace <project-root>
~~~

## 8. 可视化验收

按下表检查实际行为，不能仅凭按钮、函数或文件存在判定通过。

| 检查项 | 操作与通过标准 |
| --- | --- |
| 默认列布局 | 使用含多个起点、到达捷径、循环和返回边的图；各节点列号等于最短距离加一，所有起点在第一列 |
| 默认视图 | 首次打开显示全图及约束概览，不预先聚焦某个状态 |
| 节点拖拽 | 拖动节点后位置变化，关联边保持连接；其他节点和缩放不变，结束时不触发聚焦切换 |
| 边拖拽与置顶 | 拖动曲线或标签后路线变化，端点与节点关系不变；选中边的曲线、箭头及标签显示在最上层，重叠处可优先选中 |
| 状态聚焦 | 点击状态后仅保留该状态、直接相邻状态及相连边；再次点击同一状态恢复全图，底部没有选择列表 |
| 聚焦位置稳定 | 聚焦前后及恢复后比较节点、曲线、标签坐标和视口；数值保持一致，用户拖拽结果保留 |
| 侧栏切换 | 从侧栏边缘连续收起、展开，展开入口始终可用；可用图区随之变化，详情保留，布局和缩放不变 |
| 收起期间选择 | 先收起侧栏，再选择其他状态或迁移；侧栏保持收起，展开后显示最近选择的内容 |
| 视口操作 | 平移只改变偏移，缩放只改变视口；适应范围保留布局，重置布局恢复默认列及全图 |
| 信息与来源 | 状态展示事实、观察方法、结构和原截图；迁移展示完整 GIVEN—WHEN—THEN，条件等可选内容按实际数据出现 |
| 键盘与尺寸变化 | 无底部列表时仍可键盘选择和聚焦；画布尺寸变化后命中准确，侧栏开关可操作，图片和文字可读 |
| 模型与交付 | 页面内嵌模型及哈希与 JSON 一致；操作前后模型内容不变，项目目录仅保留约定的最终产物 |

修改模板或交互脚本后，运行 [Canvas 模拟测试](../scripts/test_canvas.js)及 Skill 要求的相关自测。实际浏览器验证覆盖点击、拖拽、重叠选中、侧栏开关及来源图片显示；模拟测试、浏览器结果和模型同步检查分别报告。

结构校验通过不代表实际交互或视觉效果已验证。无法运行浏览器或读取来源图片时，记录未验证部分及原因，不宣称这些部分通过。页面验收用于确认查看器符合本规范；应用实现及应用的功能、视觉验收按对应任务独立判断。

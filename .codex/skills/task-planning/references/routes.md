# 需求图到测试图的确定性映射

- 一个范围内原子需求对应一个主测试节点，节点身份用映射表保留；输入需求图的每条边原样映射 from/to 与来源身份，数量相等。不用路线出现次数重建边，不增加、删减或反转连接。输入若重复同向连接，拒绝生成并要求上游明确语义。
- 真实起点继承 stateGraph.entryStateIds。入口测试恰为入口需求的映射：从真实起始状态发出的迁移所对应需求；与上游显式入口列表做集合校验，展示沿用原顺序。不能用入度为零、当前所选路线第一项或未接入节点推断入口。
- 输入完整状态图保持原样。回归如已纳入范围，独立列为扩展测试与准备环境，不改变主图和业务入口；用户暂不考虑回归时不生成。
- 已有覆盖路线逐步映射 requirementId/transitionId→caseId；保留分段、重复次数、入口、条件校验结果、结构最优适用范围。相同连接在图中只一条，所属路线/步次/usageCount为元数据。
- 路线执行条件冲突或未知是就绪问题，结构映射仍可完成；不得自行改上游需求、编造连线或声称可执行最优。HTML与文档明确区分结构覆盖、条件可执行和实测通过。
- 后续明确要求优化时才建立独立候选路线；求解结果不能覆盖测试主图。少边、少节点与少访问次数是不同目标。

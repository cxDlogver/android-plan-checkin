# 第三步：只读 Canvas HTML

## 验收目标

前两步全部通过后，才初始化和生成 HTML。使用 [HTML 模板](../assets/review.html)，只读取已验收的 JSON 与派生数据；不在展示层重做需求判断、求解需求图或制造补充迁移。

| 检查项 | 通过条件 | 验收方式 |
| --- | --- | --- |
| H-INPUT | 当前状态图、需求及前两步门禁相互匹配且仍有效 | 摘要与门禁检查 |
| H-DATA | HTML 内嵌数据与验收输入一致，完整保留双图节点、边、路线和计数 | 解析内嵌 JSON 并与确定性展示投影比较 |
| H-TEMPLATE | HTML 与当前模板／渲染器生成结果一致，无残留占位符、远程依赖或可写业务操作 | 确定性重建、源码检查；维护模板时另做 JS 语法检查 |

本步骤只做静态检查。它证明数据与生成一致性，不证明真实浏览器中的可读性、像素效果、命中精度或交互运行正确；不要求浏览器观察报告或 `html_runtime_verified` 字段。

## 生成

运行 `python SKILL_DIR/scripts/analyze.py html RUN`。程序重查前两门禁，读取第一步的最短链路／迁移见证和第二步的需求图，生成离线单文件 `review.html` 并执行静态门禁。阶段报告记录实际输入和输出摘要。

本地 UI 图片如需展示，按 `ui.refs[].previewPath` 读取并内嵌；相对路径相对 RUN。有来源的 CSS 可放在状态视觉约束的 `css` 中原样列示。不依据图片或通用习惯推测设计数值。没有预览则显示来源定位与文字约束，不补画产品页面。

## Canvas 与阅读交互

- 主区域铺满可用窗口；切换完整状态图和需求覆盖图，所有节点均保留。搜索和功能定位只定位，不悄悄过滤节点。
- 状态图绘制全部业务有向边，保留平行边、回向边和自环；需求图只绘制第二步交付的实际用边。箭头方向明确，平行边错开，自环可辨。
- 支持节点拖动、空白平移、指针锚点缩放、缩放按钮、全图适配、恢复布局和缩略图定位。视图操作仅改变本地布局，不改变模型。
- 绘制和命中使用同一曲线几何；缩放／平移后逆变换坐标。支持列表选择节点和边，避免只能靠像素命中。
- 真实状态入口与入口需求分别标识，支持多个入口；不按零入度重新猜入口。

## 详情与路线

| 选择对象 | 展示内容 |
| --- | --- |
| 状态 | 当前定义、功能与事实；从各真实入口到该状态、止于该状态的最短链路；视觉约束、图片、CSS 和来源 |
| 状态迁移箭头／需求节点 | 唯一对应需求，初态、事件、条件、终态、效果；功能与视觉验收分别显示适用性和检查；各已声明条件分支的入口见证与结果；自环的独立义务和同状态理由；本需求访问次数 |
| 需求衔接箭头 | 前项、后项、共用状态与实际使用次数，不冒充开发依赖 |
| 覆盖路线面板 | 每段真实入口、完整中文步骤、初始条件、重复访问、条件重放结果；实际次数、结构下界和最优性边界 |

状态详情逐入口单列当前到达方式最后一步的结果，零步入口不编造迁移；路线每步表达前提、操作与明确结果。

功能、当前事实、迁移结果、视觉目标和来源分区呈现。多种进入方式不能把彼此的验收结果混成同一迁移。页面面向人工阅读，不输出原始 JSON、内部 ID 或技术字段堆栈；内部 ID 可用于程序关联。

动态文字使用 `textContent`，JSON 内嵌时转义 `<` 与分隔字符，来源链接只允许可审查的安全协议。模板和脚本均内嵌，无 CDN；不添加确认、编辑需求或提交业务数据的按钮。需求澄清仍在对话与确认文档中完成。

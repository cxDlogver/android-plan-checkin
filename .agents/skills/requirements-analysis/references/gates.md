# 完整门禁清单

| 门禁 | 核对内容 |
| --- | --- |
| 来源 | PRD 可读取、哈希一致、quote 来自原文；确认引用来自实际用户 |
| 澄清 | 模糊项已确认或明确移出范围；建议不能冒充答案 |
| 状态 | 真实业务事实、来自范围内 PRD、至少一个起点、可达到、有验证方法与断言 |
| 迁移 | 操作真实、有主体和条件、端点存在、结果可验证，不捏造取消/错误/返回 |
| 原子性 | 每条迁移恰好一项原子需求，每项原子需求只引用一条迁移 |
| 字段 | 每项需求含功能与视觉字段；视觉不适用有理由，自主设计不虚构设计稿 |
| 衔接图 | 节点覆盖全部原子需求；边集与终态=始态公式完全相等，保留合法环 |
| 覆盖 | included 条款有双向来源支持的需求覆盖；交付/质量单独登记 |
| 同步 | JSON/Markdown 完整，同一 revision/digest，无派生内容漂移 |
| 语义审查 | 七类逐实体审查有证据、无 fail，reviewDigest 与本版一致 |

缺人工作答输出 BLOCKED；结构或语义不合规输出 FAIL；全部通过才输出 PASS。脚本无法证明自然语言谓词、业务事件和人工作答真实性，也不能自动证明 PRD 无漏条款；必须实际阅读来源并记录语义审查证据。分析门禁不代表实现验收。

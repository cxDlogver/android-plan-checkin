# 路径与执行规划

## 1. 路径、准备方案与可集中范围

初始化前只读任务规划原件；初始化后使用验收副本。coverage.sequence 是逻辑访问顺序，visitIndex 从零开始。保留其最少访问序列和重复节点；会话只对连续区间分组。普通衔接要求上一实际终态等于当前初态；声明起点和独立用例允许重新准备。

先读取各用例检查、环境、对象及数据/Mock 生命周期，审查候选准备方案 profiles。每项记录：

| 字段 | 含义 |
| --- | --- |
| id | 准备方案名称 |
| command、cwd | 实际驱动入口及工作目录 |
| environments、resources | 能提供的环境及独占资源 |
| setupUnits | 每次准备该上下文需要实际执行的启动、连接或共享数据准备单元 |
| contextKey | 能保持同一对象、输入与共享准备结果的上下文身份 |
| eligibleVisits | 驱动和数据边界确实支持的访问下标 |

同一 contextKey 必须描述相同的完整环境与准备单元；不同驱动只有在真实保留上下文时才能共用该身份。不能为了减少指标，把不兼容的数据、Mock 或宿主声明为同一上下文。独立用例在访问内部仍需隔离 fixture，不因共享进程继承主路线数据。

同一访问的全部本轮检查环境必须被方案覆盖。连续访问共享准备、命令和生命周期时集中执行；不能为图形排列、页面相似或脚本方便而改变顺序。缺少必要环境或执行能力时规划不通过，不能声明为已覆盖。

## 2. 最少准备与重放算法

在固定原路径和已审查候选方案内，用动态规划选择连续分组。状态为“下一访问下标、之前保留的上下文”。每次枚举可覆盖该下标的方案及其能连续完成的区间。

按以下字典序选择成本最小解：

1. 额外进入访问数最少。原路径节点数固定；上下文切换丢失前提时，从声明起点对状态衔接做 BFS，计算到当前 given 的最短必要前缀。
2. 环境准备次数最少。上下文相同时复用完整准备，不重复计数；上下文改变时计入该方案 setupUnits 的数量。
3. 执行会话数最少。前两项相等时合并更多连续用例；最终按方案 ID 和稳定区间顺序选定唯一结果。

每个候选区间的成本加上后缀最优成本，选取最小值。输出 sessions 及 planning.objective，其中 routeVisits、additionalEntryVisits、preparationCount、sessionCount 分别记录原访问数、额外进入数、准备单元次数和会话数。

sessions 记录 id、profileId、from、to、command、cwd、environments、resources、entryReplay。所有区间无遗漏、无重叠地覆盖原序列；entryReplay 不写入或改写原 coverage.sequence。原有必要重复节点不能去重。

该最优结论限于给定路径和真实、完整的候选能力声明；它不证明候选方案本身完整或驱动声明真实。实际准备、重放与复用要有运行记录，不能把规划成本当作已经发生的实际次数。适配矩阵内部必需的环境输入仍按用例执行，不为减少指标删去矩阵行。

轮次清单在会话计划与合同初始化之后生成，规则见[验收执行计划](execution-plan.md)。轮次是连续逻辑分组，不能把轮数当作会话数；默认初态/夹具边界不证明全局最优恢复成本。

## 3. 执行会话与逐次提交

一个脚本可以覆盖多个用例，复用应用、设备和父进程；每次访问必须 await submit，确认合同与 HTML 已同步且 canAdvance=true 后继续。不要先跑完全部运行器用例再跑原生用例；同次访问多环境检查在当前提交点汇合。

父进程未退出时逐项 run.exitCode 写 null，不能伪填零。每步通过由该次实际观察和断言证明。外层启动器在真实进程退出后 close-session，登记真实退出码与输出。会话未成功收尾不能通过 finish；后续汇总错误也不能无依据重写此前已关闭访问。

## 4. 衔接、重复访问与恢复

entry.kind=handoff 时指向已关闭、有效的前项，且两端状态相同。entry.kind=initial 只用于声明起点或独立隔离用例。entry.kind=replay 时，从允许起点经真实动作到达当前 given，记录最短前缀及证据；不能直接设置目标画面。

TC-A → TC-B → TC-A 中，第一次 TC-A 的当前访问通过并同步后可进入 TC-B；TC-A 汇总为 partial，待第二次必要访问也完成才为 passed。任一当前访问失败或同步失败都停止在该访问，不能把未来访问预填为通过。

修复后从最早受影响位置继续；仍能证明当前初态时可复用会话，否则重放最短必要前缀。额外恢复次数如实记录，不重写原最优路线。原索引固定后若需改变需求路径或环境能力，先返回相应规划审查，不能静默更改已提交会话。

提交中断时保留 active 并恢复同一提交，不删除标记绕过门禁。写入使用独占锁，确认旧写入者已经退出后才能恢复残留锁。

# Skill Creator（项目发现入口）

这是当前仓库的 Codex Skill 发现入口，不在此重复维护编写规范。

开始工作时，先读取 [项目级 Skill Creator](../../../.codex/skills/skill-creator/SKILL.md) 并按其约束创建、修改或审查 Skill。需要评估具体规则时再读取其 `references/review-rubric.md`。

本入口与 `.codex/skills/skill-creator/` 是同一项能力；禁止在此另写一套可能冲突的原则。

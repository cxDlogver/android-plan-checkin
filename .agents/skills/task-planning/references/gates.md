# 任务规划门禁

1. 来源与上游门禁：文件可读、哈希与语义摘要匹配、无未确认歧义。
2. 用例映射：原子需求逐条 primary 1:1、非迁移要求有 supporting；scenario 例外说明理由。
3. 断言与步骤：每条功能/视觉标准映射，预期和观测方法可执行；准备/操作/观测/清理都明确。
4. 图与顺序：有效端点、根无入边及外部业务前置；所有非根有入边且可达；实际进入只能由本次刚 pass 的前序沿边进入。
5. 遍历：覆盖全部用例，边真实存在，统计重复，最优性说明有下界证据，不虚构最优。
6. 执行记录：not_run不含实际值；pass/fail有逐断言观测、命令、退出码及可验证证据；拒绝跳节点、前序失败、历史结果复用。
7. 实现计划：模块与文件明确、开发依赖无环、全部需求/用例有落实任务，完成标准可验证。
8. 默认无浏览器：仅unit/integration层级，DOM模拟和样式契约的布局验证局限被明确记录。
9. 产物：JSON/Markdown齐全，同一revision/digest且内容与模型一致。
10. 报告：规划检查结果与真实应用执行状态分开，不能把规划PASS写成应用通过。
